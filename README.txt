# Academia Cyber MX™

Plataforma SaaS Demo de E-Learning con Testing Académico y Simulación de Evaluaciones de Ciberseguridad.

Desarrollado como prototipo profesional para demostración empresarial.

---

## 🚀 Características

- Landing corporativa profesional
- Sistema de Login con roles (Alumno / Administrador)
- Panel de estudiante
- Sistema de cursos
- Sistema de evaluación interactiva
- Panel administrativo
- Diseño profesional responsive
- Arquitectura preparada para escalar a 200 alumnos
