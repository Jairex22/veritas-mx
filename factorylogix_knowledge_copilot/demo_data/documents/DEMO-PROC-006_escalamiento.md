# DEMO - Procedimiento: Escalamiento de incidentes de FactoryLogix

> DOCUMENTO DEMO. No es un procedimiento oficial.

## Qué información necesita MES para investigar un incidente

Palabras clave: información para MES, investigar incidente, datos del incidente

### Respuesta breve
Soporte MES necesita datos precisos para reproducir el problema: Work Order, serial, estación, operación, mensaje de error exacto, hora aproximada y captura de pantalla.

### Pasos
1. Anota la Work Order y el serial afectado.
2. Anota la estación y la operación.
3. Copia el mensaje de error exacto o toma una captura de pantalla.
4. Registra la hora aproximada y cuántas unidades están afectadas.
5. Describe qué intentabas hacer cuando ocurrió el problema.

### Resultado esperado
MES recibe un paquete completo y puede investigar sin pedir información adicional.

## Cómo escalar un problema de FactoryLogix

Palabras clave: escalar, escalamiento, escalate, problema de FactoryLogix

### Respuesta breve
Escala primero al supervisor de línea. Si el problema afecta a varias unidades o detiene la línea, el supervisor contacta a Soporte MES y crea un incidente con el paquete de información.

### Pasos
1. Informa al supervisor de línea.
2. Crea el incidente en el asistente con la información requerida por MES.
3. El supervisor confirma la urgencia (línea detenida = urgencia crítica).
4. Soporte MES asigna el caso y da seguimiento.

### Cuándo detenerse
Detén la operación si el sistema permite avanzar unidades con datos incorrectos.

### Cuándo escalar
Escala de inmediato con urgencia crítica si la línea está detenida.
