Diagnóstico básico de conectividad OData

Palabras clave: OData, conectividad, Analytics, error 401, error 500, timeout

Respuesta breve

Los errores de conectividad OData suelen deberse a credenciales inválidas (HTTP 401), permisos insuficientes (HTTP 403), errores del servidor (HTTP 500) o tiempo de espera agotado.

Pasos

  1. Verifica que la URL del servicio OData de Analytics sea la URL interna aprobada.
  2. Prueba el acceso al documento de metadata del servicio desde el navegador del equipo autorizado.
  3. Si recibes 401, solicita a MES validar la cuenta de servicio.
  4. Si recibes 500 o timeout, registra la hora y escala a Soporte MES.

Cuándo escalar

Escala a Soporte MES e IT si el servicio OData no responde para ningún usuario.
